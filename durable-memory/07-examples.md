# Examples and independent oracles

Every example is a worked problem with a known answer that the script asserts before drawing.
Sixteen examples, grouped as in the README:

| Example | Oracle asserted | Drawn with |
| --- | --- | --- |
| cylinder_wake | Strouhal number in 0.15..0.4 (measured 0.316 at Re 133; Schaefer-Turek 0.30 at Re 100, blockage 0.24) | lmplot (vorticity + lift/drag) and GIF |
| cavity_ghia | centre u/U = -0.20581 within 0.01, steady state, Mach < 0.3 | lmplot 3 panels with the Ghia 1982 tables inlined |
| cavity_vortex | vortex centre within 0.035 of Ghia at Re 100 and 400 (measured within one cell) | lmplot stream-function contours |
| channel | Poiseuille centre 0.0018; exact start-up series drawn | lmdraw sketch + two plots |
| shear_decay | exp(-nu k^2 t) amplitude | lmplot |
| cantilever_beam | tip -0.756 (EB 0.75 + Timoshenko 0.006), stress 3q(L-x)^2/h^2, tip slope 0.1 | lmdraw sketch + plots |
| cantilever_3d | tip deflection; cells extruded at deformed corners, coloured by sigma_xx | lmcad render embedded in lmdraw |
| plate_hole | K_t in 2.85..3.2 (measured 3.023; Heywood 3.03 for d/W = 0.1); Kirsch curve drawn | lmplot; mesh generated by the script |
| elastic_stretch | affine patch test, L2 error < 1e-7 (measured < 1e-11) | lmdraw meshes |
| insulated_wall | flux 25/R in brick and wool, interface temperature, U-value sweep 1/sum(t/k) | lmdraw wall section + sweep |
| heated_cube | core 0.0562128 (double series) within 2e-4 | lmcad voxel cutaway in lmdraw |
| heat_clock | centre exp(-2 pi^2 t) within 0.012 at 24 times | lmplot dashboard and GIF |
| heated_plate | diffusion of a two-bump profile | lmplot |
| fem_convergence | halving h divides the error by 2^(p+1) within 6% for p = 1, 2, 3 | lmplot log-log |
| poisson, sine_dome | exact quadratic / eigenmode solutions | lmplot |
| quickstart | u(0.5,0.5) = 0.5 | lmdraw pipeline diagram |

Notes that matter when changing them:
- Channel walls are halfway outside the fluid nodes, so the exact profile is evaluated at
  y = j + 0.5; H = 12 gives the 0.0018 centre maximum.
- plate_hole writes its own MFEM v1.0 mesh (96 x 24 graded O-grid, attributes 1 hole, 2/3
  grips, 4 free) with sin/cos from Taylor series because lmscript has no trig functions.
  Poisson ratio 0 makes the clamped grips an exact far field.
- cylinder_wake: the force signal contains the channel's wall-to-wall acoustic mode (period
  2 ny / c_s = 277 steps); the period is taken from a velocity probe 3 D downstream and the
  forces are shown as 300-step running means. Lift amplitude is larger than for an isolated
  cylinder because the periodic x direction makes it a row of cylinders 20 D apart.
- Interpolated lmdraw coordinates must be floats: use `floor(v) + 0.5` or rounded strings.
- lmcad reads node data through `read_keyframes_csv` (header t,x,y,z,r,g,b, t strictly
  increasing, colours in 0..1, at most 4096 rows); renders are embedded in lmdraw as a
  base64 data URI (`base64 -i FILE`, which GNU and macOS both accept, falling back to `base64 FILE`).
- Example lmscript has no try/catch: ffmpeg presence is checked by scanning PATH before
  `system ffmpeg ...`, because spawning a missing command throws.

No upstream solver code or test data is copied beyond published benchmark values (Ghia et al.
1982 tables, Heywood's K_t formula, series solutions computed here).
